Некоторые функции в Python имеют **необязательные параметры**. Это значит, что для них заранее задано значение по умолчанию, и при вызове можно этот параметр не указывать.

![Автосервис](./assets/default-parameters.png)

Рассмотрим встроенную функцию `round()`, которая округляет число:

```python
result = round(10.25, 0)  # 10.0
```

Мы передали в нее два значения:

- Число, которое нужно округлить.
- Точность округления, `0` означает, что округление будет до целого числа.

Так как чаще всего нужно именно округление до целого, создатели функции `round()` сделали второй параметр необязательным: если его не указать (значение по умолчанию — `None`), округление тоже идет до целого числа. Отличается только запись результата: с `0` это `10.0`, а без второго аргумента — `10`:

```python
result = round(10.25)  # 10
```

Если нужна другая точность, то ее можно указать явно:

```python
# округление до одного знака после запятой
result = round(10.25, 1)  # 10.2
```

```text
round(10.25, 1)  →  аргументы: 10.25, 1       →  10.2
round(10.25)     →  аргументы: 10.25, (None)  →  10
                                       └── значение по умолчанию
```

В сигнатуре `round()` обязательный параметр `number` стоит перед необязательным `ndigits`. У другой функции количество параметров и их значения по умолчанию могут отличаться.

## Как читать документацию функции

Документация описывает, какие данные принимает функция и какой результат возвращает. Сигнатура в начале справки показывает имя функции, параметры и их порядок. Текст под ней объясняет назначение параметров и поведение функции. Чтобы составить вызов, нужны обе части.

Разберём [справку о `round()`](https://docs.python.org/3/library/functions.html#round). В её начале записана сигнатура `round(number, ndigits=None)`. Имена `number` и `ndigits` обозначают параметры. При вызове на их места подставляются конкретные значения, например `round(10.25, 1)`.

В таблице сопоставлены части сигнатуры и аргументы этого вызова.

| Часть сигнатуры | Что она означает | В вызове `round(10.25, 1)` |
| --- | --- | --- |
| `round` | Имя функции | Вызываем `round()` |
| `number` | Обязательный параметр, число для округления | Передаём `10.25` |
| `ndigits=None` | Необязательный параметр со значением по умолчанию `None` | Передаём `1` вместо значения по умолчанию |

Знак `=` в `ndigits=None` сообщает о значении по умолчанию. Из этой записи видно, что второй аргумент можно пропустить. Как именно функция использует `None`, объясняет описание под сигнатурой. У `round()` пропуск второго аргумента означает округление до целого числа.

Под сигнатурой начинается описание результата. Английское слово `return` означает «вернуть». В справке о `round()` сказано, что функция возвращает число, округлённое до указанного количества знаков после десятичного разделителя. Там же поясняется, что без `ndigits` результатом будет целое число. Сигнатура показывает допустимый вызов, а описание позволяет понять его результат.

Проверим оба случая в интерактивной оболочке Python (REPL). Знаки `>>>` обозначают приглашение оболочки, строки под вызовами показывают результат.

```console
>>> round(10.25, 1)
10.2
>>> round(10.25)
10
```

Здесь первый вызов передаёт точность `1` и получает число `10.2`. Второй оставляет значение `ndigits` по умолчанию и получает целое число `10`. Так мы сопоставляем сигнатуру, объяснение в документации и результат выполнения.

## Обозначения в справке

В справочнике могут встречаться служебные обозначения. Они помогают прочитать сигнатуру и при вызове не передаются в функцию.

| Запись в справке | Как её читать |
| --- | --- |
| `round(number, ndigits=None)` | У `ndigits` есть значение по умолчанию, аргумент можно пропустить |
| `round(number[, ndigits])` | Другой способ обозначить необязательный аргумент в справочниках. Квадратные скобки не входят в вызов |
| `abs(number, /)` | Параметр перед `/` принимает аргумент по позиции. Знак `/` не является ещё одним параметром |

Например, запись `abs(number, /)` описывает функцию с одним параметром. Вызов `abs(-5)` передаёт ему число `-5` и возвращает `5`. Ни имя `number`, ни служебный знак `/` в такой вызов не копируются.

Если браузер переводит страницу, имена функций, параметры и символы в сигнатуре нужно сверять с оригиналом. В коде используются исходные имена из документации. Например, перевод слова `number` как «число» помогает понять описание, а в вызов по-прежнему подставляется само значение `10.25`.

## Работа с незнакомой функцией

Чтение справки начинается с задачи. Например, для округления цены до одного знака после запятой в сигнатуре `round()` находим число и точность, в описании проверяем смысл точности, затем пробуем вызов `round(10.25, 1)`. Если результат соответствует описанию, этот вызов можно использовать в программе.

У другой функции будут свои параметры и правила. По её сигнатуре мы определяем, какие аргументы передать, по описанию узнаём результат и ограничения, а на небольшом примере проверяем своё понимание.
