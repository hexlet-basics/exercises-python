Текст сообщения может содержать символы `<`, `>` и `&`. При выводе на HTML-странице браузер воспринимает их как часть разметки. Пакет стандартной библиотеки `html` заменяет такие символы специальными последовательностями и сохраняет текст сообщения.

## Задание

Реализуйте функцию `escape_html(text)`. Она принимает строку и возвращает результат функции `escape()` из пакета `html` с параметрами по умолчанию. При этом также заменяются одинарные и двойные кавычки.

```python
print(escape_html("<b>A & B</b>"))  # => &lt;b&gt;A &amp; B&lt;/b&gt;
print(escape_html('"Hello"'))  # => &quot;Hello&quot;
print(escape_html("It's ok"))  # => It&#x27;s ok
print(escape_html("Hello"))  # => Hello
```

## Подсказки

- `html` является обычным пакетом стандартной библиотеки. Его файл _\_\_init\_\_.py_ предоставляет функцию `escape()`
- Можно импортировать пакет через `import html` или саму функцию через `from html import escape`
- [Документация html.escape](https://docs.python.org/3/library/html.html#html.escape)
