When a user registers on a site, the program checks that the password is long enough — more than 5 characters. Write the function `is_long_word()`, which returns `True` if the length of the given word is greater than 5 characters, and `False` otherwise.

An example of how it works:

```python
print(is_long_word("apple"))   # => False
print(is_long_word("banana"))  # => True
```
